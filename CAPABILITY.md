# Evidence-driven capability control (opt-in)

`route` accepts an outcome contract in `control`: selective context, tool readiness,
dependency-aware work planning, receipt-based acceptance and bounded native-effort escalation.
Existing callers need not opt in. The core returns decisions, not executed worker actions.

- [API contract and host responsibilities](docs/capability-controller.md)
- [七個可執行參考範例](docs/seven-principles.zh-TW.md)
- Run `npm run examples:capability` offline. The fictional model names and receipts do not
  represent live provider calls or actual Crew/Night Lamp work.

No installed agent settings, model bans, account permissions or payment policy are changed.
